# Contact Book Using Python Dictionaries
## Description
A simple command-line contact book developed using Python.
It allows users to add, search, update, delete, and view
contacts using a dictionary.
## Objectives
- Understand Python dictionaries and key-value pairs.
- Implement CRUD operations.
- Validate duplicate phone numbers.
- Practice functions, loops, and conditional statements.
## Features
- Add new contacts
- Search contacts by phone number
- Update contact details
- Delete contacts
- View all saved contacts
- Validate duplicate phone numbers
- Handle invalid menu choices
## Technologies Used
- Python 3
## How to Run
1. Install Python 3, or open an online Python compiler.
2. Open contact_book.py.
3. Run the program.
4. Select an option from the menu.
## Concepts Learned
- Dictionaries
- Key-value pairs
- Functions
- Loops and conditional statements
- CRUD operations
- Input validation
